# 素材分类与安放规则

## 总原则

每个素材先判定一个主类目，再决定 entity、taxonomy、annotation 和项目引用。不要只靠文件夹或 tags 管理。

主类目必须回答：这个素材的生产主体是什么？

每个主体资产文件夹还必须有 Markdown 信息卡，信息卡字段见 asset-info-card-standard.md。分类规则决定“放哪里、叫什么、关联谁”；信息卡决定“其他 Agent 如何理解和使用它”。

## 主类目表

| 主类目 | 适用素材 | taxonomy domain | entity 类型 | 必要注释 |
|---|---|---|---|---|
| 场景 | 场景图、背景、空间设定、环境参考 | scene | scene | scene_concept |
| 角色 | 角色设定图、表情、动作姿态、三视图 | character | character | character_profile |
| 服装 | 角色穿着、服饰套装、造型变化 | costume | costume + character | costume_spec |
| 装备 | 穿戴/携带的功能性装备、武器、装置 | prop 或 gear | prop / other | prop_function 或 equipment_spec |
| 道具 | 剧情道具、手持物、置景物 | prop | prop | prop_function |
| 动作 | 动作参考、姿势、运动节奏 | reference / motion | character 可选 | motion_note |
| 镜头 | 分镜、构图、运镜参考、镜头方案 | reference / storyboard | scene 可选 | shot_note |
| 音频 | 配音、音乐、音效、环境声 | audio | character / scene 可选 | source_rights + production_note |
| 特效 | 光效、粒子、魔法、爆炸、屏幕特效 | effect / reference | scene / prop 可选 | vfx_note |
| 风格参考 | 色彩、光影、画风、材质、竞品参考 | reference | style 可选 | style_note |
| 文档 | brief、脚本、设定说明、授权文件 | document | project 可选 | production_note |
| 交付物 | 成片、封面、导出包、字幕文件 | delivery | project 可选 | delivery_note |

## 分类决策树

1. 画面主体是空间或环境 → 场景。
2. 画面主体是人物/动物/IP 形象 → 角色。
3. 主体是角色身上的穿着造型 → 服装。
4. 主体是可穿戴、可展开、可操作的功能装置 → 装备。
5. 主体是被拿起、摆放或推动剧情的物件 → 道具。
6. 主体是姿态、运动、走位、表演节奏 → 动作。
7. 主体是构图、镜头顺序、机位、转场 → 镜头。
8. 主体是声音 → 音频。
9. 主体是画风、色彩、光影、材质 → 风格参考。
10. 不能判断 → 留在暂存区，不正式入库。

## 场景素材

标题格式：

场景 - 场景名 - 用途

示例：

- 场景 - 月宫外景 - 清晨氛围参考
- 场景 - 地下机房 - 空间设定
- 场景 - 林间小路 - 光影参考

必须记录：

- 地点类型：室内、室外、抽象空间、舞台布景。
- 时间与氛围：清晨、夜晚、雨天、压迫、温暖等。
- 连续性锚点：主要色彩、地标、门窗位置、光源方向。
- 素材信息卡中的场景设定和项目用途。

## 角色素材

标题格式：

角色 - 角色名 - 用途

示例：

- 角色 - 咕咕嘎嘎 - 角色设计板
- 角色 - 咕咕嘎嘎 - 表情参考
- 角色 - 银发少女 - 战斗姿态参考

必须记录：

- canonical_name / alias。
- 外观锚点：发型、脸型、体型、颜色、标志物。
- 表演锚点：性格、动作习惯、情绪范围。
- 禁止改动项。
- 素材信息卡中的角色身份、外观锚点和表演规则。

## 服装素材

标题格式：

服装 - 角色名 - 服装名或用途

示例：

- 服装 - 咕咕嘎嘎 - 初始登场服
- 服装 - 银发少女 - 雪地斗篷

必须记录：

- 所属角色。
- 剪影、颜色、材质。
- 可使用场景和禁用场景。
- 是否允许局部变化。
- 素材信息卡中的所属角色、材质和连续性规则。

## 装备与道具素材

装备更强调穿戴/操作/功能，道具更强调剧情物件或置景物。

装备示例：

- 装备 - 机械羽翼 - 展开状态设定
- 装备 - 护目镜 - 近景细节
- 装备 - 能量手套 - 发光效果

道具示例：

- 道具 - 银色钥匙 - 剧情关键道具
- 道具 - 旧地图 - 手持参考
- 道具 - 桌面茶杯 - 置景道具

必须记录：

- 功能和剧情意义。
- owner / used_by。
- 与角色或场景的交互方式。
- 尺寸、材质、发光/运动状态。
- 素材信息卡中的来源、材质、功能、限制条件和镜头使用方式。

## 音频素材

标题格式：

音频 - 主体名 - 用途

示例：

- 音频 - 咕咕嘎嘎 - 试配音第一版
- 音频 - 月宫外景 - 环境声
- 音频 - 战斗段落 - 打击音效

必须记录：

- audio_role：voice、music、sfx、ambience。
- 关联角色/场景。
- 授权与来源。
- 可用时段或禁用场景。
- 素材信息卡中的音频角色、情绪、节奏和使用约束。

## 风格参考素材

标题格式：

风格参考 - 风格名 - 方向

示例：

- 风格参考 - 水墨暖光 - 色彩方向
- 风格参考 - 低饱和科幻 - 材质方向

规则：

- 风格参考不能当成角色或场景真相。
- 若参考图里包含角色/场景，也必须说明“只参考风格，不继承主体设定”。

## 安放规则

插件内可见资产以元数据分类为准；物理目录只作为来源与缓存承载。

暂存区：

- 未判断、刚上传、待审核素材。
- 不能长期保留。

原始素材：

- 通过来源与授权检查的原始导入。

工作素材：

- 已加工、裁切、清洗、去背景、生成中间版本。

派生素材：

- thumbnail、proxy、contact sheet、转码文件。

归档：

- 不再 active 使用但需要保留证据的旧素材。

## 防混杂规则

- 角色图不能放进场景分类，即使背景很明显。
- 服装不能只挂角色分类；必须独立为服装，并说明所属角色。
- 装备和道具不能混写；能穿戴/操作的优先装备，剧情物件/置景物优先道具。
- 风格参考不能被项目直接当作正式生产资产，除非已转化为正式角色/场景/道具素材。
- 同名角色不同服装必须区分角色 entity 和服装 entity。
