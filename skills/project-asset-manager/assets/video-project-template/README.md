# Video Project Template

这是一套可直接复制使用的标准视频项目骨架。

## Recommended Copy Target
`projects/active/<project-name>/`

## Structure
- `project.yaml`：项目元信息
- `01-brief/`：需求、目标、受众、平台与成功标准
- `02-research/`：热点、竞品、参考与研究记录
- `03-storyboards/`：分镜、镜头脚本、节奏设计
- `04-specs/`：分辨率、时长、比例、格式、平台规格
- `05-asset-map/`：项目与素材库的映射清单
- `06-prompts/`：提示词、协议包、迭代记录
- `07-production/`：生成、剪辑、配音、后期过程记录
- `08-review/`：模型复核、人工验收、问题清单
- `09-delivery/`：交付说明、版本说明、发布备注
- `99-archive/`：项目结束后的归档补充

## Minimal Startup Checklist
1. 填 `project.yaml`
2. 填 `01-brief/brief.md`
3. 填 `04-specs/spec.md`
4. 在 `05-asset-map/assets-map.md` 写清素材位置
5. 再进入研究、生成与后期流程
